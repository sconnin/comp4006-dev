# comp4006-dev

Draft materials for **COMP 4006 — Python Programming in Data Science and AI**, a ten-week
introductory course. One unit per week:

| Week | Topic | Week | Topic |
|---|---|---|---|
| 1 | Intro / Variables / Boolean Logic | 6 | Dictionaries |
| 2 | Control Flow | 7 | File I/O & Exceptions |
| 3 | Functions | 8 | Classes |
| 4 | Lists & Tuples | 9 | Recursion |
| 5 | Strings & Sets | 10 | Independent Project |

## What is in this repository

This is a **public mirror carrying only the files students receive.** Each week folder holds at
most one tracked file, the assignment template:

```
NN-topic/assignment-N.py
```

Students rename it to `hw<N>_firstname_lastname.py` before submitting. Assignments that require
more than one file are submitted as `hw<N>_firstname_lastname.zip`.

Also tracked at the root:

- `code-rubric.docx` — the 80-point code rubric, the only rubric students receive
- `reflection-prompts.docx` — the 20-point reflective-response template
- `publications/research-summary.md` — findings from the education research the course design draws on

Weeks 4–10 are not built yet; their placeholder files are marked `NOT YET BUILT`.

## What is deliberately absent

Instructor material is gitignored and stays local: solution sets, instructor session notes,
assignment and notes specifications, per-unit allowed-method lists, the grading rule files, and
`previous-materials/` from the earlier run of this course. The research PDFs under `publications/`
are also local — most carry terms forbidding redistribution.

A missing file in a week folder is therefore expected, not an oversight.
